# تحليل نيش الأثاث والديكور — ماجمافاي

موقع تفاعلي بيعرض تقييم تخصص ماجمافاي (معارض الأثاث والديكور) بمعايير ورقة اختيار التخصص،
مع إحصائيات سوق حديثة، ورسوم بيانية، وقائمة تنفيذ قابلة للمتابعة، وتصميم جديد لفورم الاستشارة.

**الموقع المنشور:** https://mrvoroo.github.io/Niche-Analysis/

## اللي جوّا الموقع

| القسم | المحتوى |
|---|---|
| الخلاصة | الدرجة النهائية (26 من 33) والحكم في أربع نقاط |
| ورقة التقييم | الفلاتر الستة + البونص، برسم بياني ومقارنة بالمثال المعبّى في الملف |
| أرقام السوق | نمو سوق الأثاث السعودي، حصة البيع الإلكتروني، شرائح السعر، ومؤشر أسعار السكن |
| القوة والضعف | 8 مميزات و8 تحديات، وجدول بتحويل كل تحدي لجملة نقولها للعميل |
| تقييم الموقع | فحص `magmafyogp.com` — اللي شغّال واللي محتاج تعديل |
| قائمة التنفيذ | 25 بند في 5 مجموعات، بـ checkbox محفوظ في المتصفح |
| الفورم الجديد | نموذج استشارة شغّال بالكامل، بيبني خطة مبدئية حيّة وإنت بتجاوب |
| البونص | أبو عبدالله (مرجع التنجيد من الكويت) وخبرة أودو، وأسئلة جاهزة للجلسة |

## التقنيات

- **React 18 + TypeScript + Vite**
- **[@propeldata/ui-kit](https://github.com/propeldata/ui-kit)** للرسوم البيانية والعدّادات
  (`TimeSeries`, `Leaderboard`, `PieChart`, `Counter`, `ThemeProvider`) — كلها بتشتغل ببيانات ثابتة
  عن طريق `labels`/`values` و`headers`/`rows`، من غير أي اتصال بخوادم Propel ومن غير access token.
- هوية ماجمافاي: نفس الألوان والخطوط من `magmafyogp.com` (El Messiri, Tajawal, Aref Ruqaa, Space Grotesk).

## التشغيل محلياً

```bash
npm install
npm run dev        # تطوير
npm run build      # بناء إلى مجلد docs/
npm run preview    # معاينة البناء
```

## النشر

البناء بيطلع في مجلد `docs/` وGitHub Pages بيخدمه من فرع `main`.
بعد أي تعديل: `npm run build` ثم commit و push لمجلد `docs/` كمان.

`base` في `vite.config.ts` مضبوط على `/Niche-Analysis/` عشان يشتغل على GitHub Pages.

## ملاحظات على البيانات

- كل رقم في الموقع مربوط بمصدره، والمصادر كلها في آخر الصفحة (15 مصدر).
- أرقام أحجام السوق بتختلف بين التقارير لأن كل واحد بيعرّف السوق بشكل مختلف — وده مذكور عند كل رقم.
- أي رقم تقديري مكتوب عليه «تقديري» صراحة. أضعف بند من ناحية التحقق هو عدد العملاء،
  ومحتاج عدّ فعلي على خرائط جوجل زي ما الملف بيطلب.
- علامات قائمة التنفيذ متخزّنة في `localStorage` على جهاز المستخدم فقط، ومش بتتشارك.
