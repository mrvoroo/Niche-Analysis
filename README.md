# تحليل نيش الأثاث والديكور — ماجمافاي

تطبيق ويب تفاعلي بيقيّم تخصص ماجمافاي بمعايير ورقة اختيار التخصص، وبيشتغل كأداة شغل مستمرة:
أوراق تخصص قابلة للتعديل والمقارنة، قائمة تنفيذ، وحفظ دائم على جوجل شيت.

**الموقع:** https://mrvoroo.github.io/Niche-Analysis/

## الأقسام الأربعة

| التبويب | المحتوى |
|---|---|
| **التحليل** | الدرجة النهائية (26 من 33)، ورقة التقييم، أرقام السوق برسوم بيانية، القوة والضعف، فحص `magmafyogp.com`، قائمة تنفيذ من 25 بند، تصميم فورم الاستشارة الجديد، والبونص |
| **مقارنة المرشحين** | الأثاث والديكور (26) مقابل التصميم الداخلي والتشطيبات (24) والمطابخ والخزائن (24)، فلتر بفلتر مع الأدلة |
| **أوراق التخصص** | أوراق قابلة للطي: كل ورقة فيها الفلاتر الستة + الأسئلة العشرة بتاعة الغوص. تقدر تضيف وتنسخ وتحذف وتقارن ورقتين جنب بعض |
| **الإعدادات** | ربط جوجل شيت كقاعدة بيانات، وتثبيت التطبيق على الموبايل |

## الحفظ الدائم (جوجل شيت)

الشغل بيتحفظ في المتصفح على طول. الربط بجوجل شيت بيخلّيه يتحفظ برّه المتصفح ويوصلك من أي جهاز.

**التركيب مرة واحدة:**

1. افتح شيت **[«Magmafy — قاعدة بيانات تحليل النيش»](https://docs.google.com/spreadsheets/d/1EFf3vTRHU52ZdoaPredoVs5OOGwAT7nnEZgt7DlGVuw/edit)** على درايف `magmafyogp@gmail.com`
2. Extensions ← Apps Script
3. امسح الكود الموجود والصق [`apps-script/Code.gs`](apps-script/Code.gs) واحفظ
4. Deploy ← New deployment ← النوع **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
5. انسخ الرابط (بينتهي بـ `/exec`) وحطه في تبويب الإعدادات في الموقع

> كل الخطوات دي لازم تتعمل وإنت داخل بحساب `magmafyogp@gmail.com`، لأن الـ deploy بيشتغل بصلاحيات الحساب اللي عمله.

الشيت بيتعبّى تلقائياً بأربع تبويبات: البيانات (JSON)، أوراق التخصص، قائمة التنفيذ، وسجل التعديلات.

> **أمان:** إعداد `Anyone` معناه إن أي حد معاه رابط الـ Web App يقدر يقرا ويكتب. ما تنشرش الرابط.
> للإلغاء: Deploy ← Manage deployments ← Archive.

## تطبيق الموبايل (PWA)

- **أندرويد (كروم):** قائمة المتصفح ← تثبيت التطبيق
- **آيفون (سفاري):** زر المشاركة ← إضافة إلى الشاشة الرئيسية (لازم سفاري مش كروم)
- **الكمبيوتر (كروم):** أيقونة التثبيت في شريط العنوان

التطبيق بيشتغل أوفلاين عن طريق Service Worker، والتعديلات بتتزامن مع الشيت أول ما النت يرجع.

## التقنيات

- **React 18 + TypeScript + Vite**، وتنقّل بالـ hash عشان يشتغل على GitHub Pages من غير إعدادات خادم
- **[@propeldata/ui-kit](https://github.com/propeldata/ui-kit)** للرسوم والعدّادات (`TimeSeries`, `Leaderboard`, `PieChart`, `Counter`, `ThemeProvider`) — كلها ببيانات ثابتة عن طريق `labels`/`values` و`headers`/`rows`، من غير أي اتصال بخوادم Propel ومن غير access token
- هوية ماجمافاي: نفس ألوان `magmafyogp.com` وخط **El Messiri** للعناوين والنص

## البناء والنشر

```bash
npm install
npm run dev        # تطوير
npm run build      # بناء
npm run preview    # معاينة
```

المصدر في `app/`، والبناء بيطلع في **جذر المستودع** (`index.html` + `assets/`) عشان GitHub Pages
يخدمه مباشرة. الـ `base` نسبي (`./`) فالموقع بيشتغل من أي مسار.

بعد أي تعديل: `npm run build` ثم commit للملفات المولّدة في الجذر كمان.

## ملاحظات على البيانات

- كل رقم مربوط بمصدره، والمصادر كلها (20 مصدر) في آخر الصفحة.
- أحجام السوق بتختلف بين التقارير لأن كل واحد بيعرّف السوق بشكل مختلف — وده مذكور عند كل رقم.
- أي رقم تقديري مكتوب عليه «تقديري» صراحة. أضعف بند من ناحية التحقق هو عدد العملاء،
  ومحتاج عدّ فعلي على خرائط جوجل زي ما الملف بيطلب.
